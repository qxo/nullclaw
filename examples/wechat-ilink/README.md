# WeChat iLink 插件

这是一个用于 nullclaw 的 WeChat 通道插件，直接调用微信 iLink Bot API 实现。

## 功能特性

- 支持微信扫码登录
- 支持消息收发
- 支持媒体消息（图片、语音、视频、文件）
- 支持群组消息处理
- 支持消息监控（长轮询）
- 支持自动登录和状态检查
- 支持消息过滤（白名单、关键词过滤）
- 支持自动回复功能
- 控制台直接显示二维码

## 安装步骤

### 1. 安装依赖

在插件目录中运行：

```bash
npm install
```

这将安装 `qrcode-terminal` 包及其依赖。

### 2. 配置 nullclaw

将 `config.example.json` 复制到 nullclaw 配置目录：

```bash
# Windows
copy config.example.json %USERPROFILE%\.nullclaw\config.json

# Linux/macOS
cp config.example.json ~/.nullclaw/config.json
```

### 3. 启动插件

使用 nullclaw 命令启动 WeChat 通道：

```bash
zig-out\bin\nullclaw.exe channel start wechat_ilink
```

## 配置选项

### 主要配置项

- `allow_from`: 允许发送消息的用户 ID 列表，使用 `["*"]` 表示允许所有用户
- `group_policy`: 群组消息策略，可选值：`allowlist`（仅允许白名单用户）
- `enable_media`: 是否启用媒体消息支持（图片、语音、视频、文件）
- `enable_voice`: 是否启用语音消息
- `enable_video`: 是否启用视频消息
- `enable_file`: 是否启用文件消息
- `auto_reply`: 自动回复配置
  - `enabled`: 是否启用自动回复
  - `message`: 自动回复的消息内容
- `message_filter`: 消息过滤配置
  - `enabled`: 是否启用消息过滤
  - `keywords`: 过滤关键词列表
  - `mode`: 过滤模式，`block`（阻止包含关键词的消息）或 `allow`（仅允许包含关键词的消息）
- `polling_interval`: 消息轮询间隔（毫秒），默认 1000ms
- `max_retries`: 最大重试次数，默认 3 次
- `timeout_ms`: 请求超时时间（毫秒），默认 30000ms
- `save_messages`: 是否保存消息到本地，默认 `true`
- `message_dir`: 消息保存目录，默认 `~/.nullclaw/workspace/wechat`

### 高级配置

插件会在 `~/.nullclaw/.weixin-token.json` 文件中存储登录状态和会话信息。
消息会保存在 `~/.nullclaw/workspace/wechat/` 目录下，按日期分类存储。

## 运行原理

1. 插件启动时，会初始化微信客户端
2. 启动消息轮询循环，定期检查新消息
3. 当收到新消息时，会发送 `inbound_message` 通知给 nullclaw
4. 支持媒体消息（图片、语音、视频、文件）的解析和传递
5. 支持群组消息的处理和过滤
6. 支持消息关键词过滤
7. 支持自动回复功能
8. 当需要发送消息时，会调用微信 API 发送消息
9. 支持自动登录和状态检查

## 登录流程

1. **首次使用**：
   - 插件会自动调用微信 API 获取二维码
   - 二维码会直接显示在控制台（ASCII art 格式）
   - 使用微信扫描二维码
   - 在微信端确认登录
   - 登录成功后，token 会保存在 `~/.nullclaw/.weixin-token.json` 文件中

2. **后续使用**：
   - 插件会自动加载保存的 token
   - 不需要重新登录，直接开始消息轮询
   - 如需重新登录，删除 `~/.nullclaw/.weixin-token.json` 文件后重启插件

## 媒体消息支持

插件支持以下类型的媒体消息：

- **图片消息**：包含图片 URL、尺寸、大小等信息
- **语音消息**：包含语音文本、播放时长等信息
- **视频消息**：包含视频 URL、播放时长、大小等信息
- **文件消息**：包含文件名、文件 URL、大小等信息

媒体消息会通过 `media` 数组传递给 nullclaw，每个媒体项包含类型和相关信息。

## 群组消息处理

- 插件会自动识别群组消息（通过 `chat_id` 和 `sender_id` 的差异）
- 支持群组消息的白名单过滤
- 自动回复功能默认不响应群组消息
- 在消息通知中会标记 `is_group: true`

## 消息过滤

插件支持两种消息过滤模式：

1. **阻止模式（block）**：阻止包含指定关键词的消息
   - 设置 `mode: "block"`
   - 在 `keywords` 数组中添加要阻止的关键词
   - 消息中包含任一关键词即被阻止

2. **允许模式（allow）**：仅允许包含指定关键词的消息
   - 设置 `mode: "allow"`
   - 在 `keywords` 数组中添加要允许的关键词
   - 消息中不包含任一关键词即被阻止

## 自动回复

插件支持自动回复功能：

- 启用后，收到非群组消息时会自动回复
- 自动回复消息可自定义
- 默认不启用，需要在配置中手动开启
- 自动回复不会响应群组消息

## 故障排除

### 常见问题

1. **登录失败**：
   - 确保网络连接正常
   - 检查微信账号状态
   - 删除 `~/.nullclaw/.weixin-token.json` 文件后重新登录
   - 检查是否有防火墙或代理限制
   - 查看插件日志了解详细错误信息

2. **消息收发失败**：
   - 检查网络连接
   - 检查微信账号状态
   - 查看插件日志了解详细信息
   - 检查消息过滤配置是否正确

3. **插件启动失败**：
   - 检查 Node.js 版本是否 >= 22
   - 检查依赖是否正确安装
   - 查看插件日志了解详细信息

4. **媒体消息无法接收**：
   - 检查 `enable_media` 配置是否为 `true`
   - 检查对应的媒体类型是否启用（`enable_voice`、`enable_video`、`enable_file`）
   - 查看插件日志了解详细信息

### 日志查看

插件会在控制台输出详细日志，包括：
- 插件启动状态
- 登录过程（包括二维码显示、扫码状态等）
- 消息收发情况
- 媒体消息信息
- 群组消息标记
- 消息过滤情况
- 自动回复情况
- 错误信息和排查建议

## 技术细节

- 直接调用微信 iLink Bot API
- 使用 JSON-RPC 协议与 nullclaw 通信
- 支持长轮询消息获取
- 实现了完整的外部通道协议
- 支持协议版本 2
- 支持媒体消息的完整解析和传递
- 支持群组消息的识别和处理
- 支持消息关键词过滤
- 支持自动回复功能

## 注意事项

- 本插件需要 Node.js 22 或更高版本
- 首次使用需要扫码登录微信
- 登录状态会保存在 `~/.nullclaw/.weixin-token.json` 文件中，下次启动时会自动恢复登录状态
- 请确保微信账号未被封禁，否则可能无法正常使用
- 二维码会直接显示在控制台，无需下载和打开图片文件
- 媒体消息功能需要在配置中启用
- 自动回复功能默认不启用，需要在配置中手动开启
- 消息过滤功能需要根据实际需求配置关键词和模式
