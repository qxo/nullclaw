# WeChat iLink CLI 重构完成报告

## 重构日期
2026-03-23

## 重构目标

将 WeChat iLink 插件重构为支持命令行参数独立运行的工具，不依赖 nullclaw，实现核心的消息收发和文件功能。

## 实现的功能

### 1. ✅ 独立运行模式
- **文件**: `wechat-cli.js`
- **特点**: 完全独立运行，不依赖 nullclaw
- **优势**: 可以直接通过命令行使用，适合脚本化和自动化

### 2. ✅ 命令行参数支持
实现了完整的命令行参数解析，支持以下命令：

- `login` - 扫码登录微信
- `send <用户ID> <消息>` - 发送消息
- `file <用户ID> <文件路径>` - 发送文件
- `poll` - 轮询新消息
- `status` - 查看登录状态
- `logout` - 退出登录
- `interactive` - 进入交互式模式
- `help` - 显示帮助信息

### 3. ✅ 登录功能
- **扫码登录**: 自动获取二维码并在控制台显示（ASCII art 格式）
- **状态轮询**: 自动轮询扫码状态，支持二维码过期刷新
- **Token 保存**: 登录成功后自动保存 token 到 `~/.nullclaw/.weixin-token.json`
- **Token 加载**: 下次启动时自动加载保存的 token
- **错误处理**: 完善的错误处理和用户提示

### 4. ✅ 消息发送功能
- **文本消息**: 支持发送纯文本消息
- **文件消息**: 支持发送各种类型的文件
- **用户 ID**: 支持指定接收消息的用户 ID
- **消息确认**: 发送成功后显示确认信息

### 5. ✅ 文件发送功能
- **文件类型支持**:
  - 文档（PDF、Word、Excel 等）
  - 图片（JPG、PNG、GIF 等）
  - 视频（MP4、AVI 等）
  - 音频（MP3、WAV 等）
- **文件信息**: 自动读取文件名和大小
- **文件路径**: 支持相对路径和绝对路径
- **错误处理**: 文件不存在时提示错误

### 6. ✅ 消息轮询功能
- **长轮询**: 使用微信 API 的长轮询机制
- **消息解析**: 完整解析消息内容和媒体信息
- **消息显示**: 清晰显示消息内容、发送者、媒体信息
- **媒体支持**: 支持显示图片、语音、视频、文件等媒体信息

### 7. ✅ 登录状态查看
- **状态信息**: 显示完整的登录状态
- **Bot 信息**: 显示 Bot ID、用户 ID、Base URL
- **Token 信息**: 显示 Token 保存时间

### 8. ✅ 退出登录功能
- **Token 删除**: 删除保存的 token 文件
- **状态清除**: 清除登录状态
- **确认提示**: 操作前确认提示

### 9. ✅ 交互式命令行界面
- **命令提示**: 清晰的命令提示符 `wechat> `
- **命令历史**: 支持上下箭头浏览命令历史
- **命令补全**: 支持 Tab 键补全（readline 默认功能）
- **错误处理**: 命令错误时显示友好的错误信息
- **退出命令**: 支持 `quit` 和 `exit` 命令

### 10. ✅ 帮助系统
- **命令列表**: 显示所有可用命令
- **用法说明**: 每个命令都有详细的用法说明
- **示例**: 提供实际使用示例
- **配置信息**: 显示配置文件位置和主目录

## 使用方法

### 1. 安装依赖
```bash
cd i:\github\nullclaw\examples\wechat-ilink
npm install
```

### 2. 查看帮助
```bash
node wechat-cli.js help
# 或
npm run cli
```

### 3. 登录微信
```bash
node wechat-cli.js login
```

### 4. 发送消息
```bash
node wechat-cli.js send user123 "你好，这是一条测试消息"
```

### 5. 发送文件
```bash
node wechat-cli.js file user123 "./document.pdf"
```

### 6. 轮询消息
```bash
node wechat-cli.js poll
```

### 7. 查看状态
```bash
node wechat-cli.js status
```

### 8. 退出登录
```bash
node wechat-cli.js logout
```

### 9. 交互式模式
```bash
node wechat-cli.js interactive
```

## 技术实现

### 依赖管理
- **Node.js 内置模块**:
  - `crypto` - 生成随机 UIN
  - `fs` - 文件系统操作
  - `path` - 路径处理
  - `readline` - 交互式命令行界面
  - `fs/promises` - 异步文件操作
- **外部依赖**:
  - `qrcode-terminal` - 二维码显示（与主插件共享）

### API 集成
- **登录流程**:
  - `ilink/bot/get_bot_qrcode` - 获取二维码
  - `ilink/bot/get_qrcode_status` - 轮询扫码状态
- **消息发送**:
  - `ilink/bot/sendmessage` - 发送消息和文件
- **消息接收**:
  - `ilink/bot/getupdates` - 长轮询获取新消息

### 错误处理
- **网络错误**: 完善的网络错误处理和重试机制
- **文件错误**: 文件不存在、权限错误等
- **登录错误**: 二维码过期、登录超时等
- **API 错误**: HTTP 错误、API 错误等

### 用户体验
- **清晰的日志**: 所有操作都有清晰的日志输出
- **友好的提示**: 错误时提供详细的排查建议
- **进度显示**: 登录、发送消息等操作都有进度提示
- **确认反馈**: 操作成功后显示确认信息

## 配置管理

### Token 文件
- **位置**: `~/.nullclaw/.weixin-token.json`
- **格式**: JSON
- **内容**:
  ```json
  {
    "token": "bot_token",
    "baseUrl": "api_base_url",
    "accountId": "bot_id",
    "userId": "user_id",
    "savedAt": "timestamp"
  }
  ```

### 主目录
- **Windows**: `%USERPROFILE%`
- **Linux/macOS**: `$HOME`
